# Magic Letter Zoo – sources and tests

`index.html` at the repo root is the shipped game (single file, no build step needed to deploy).
The script inside it is assembled from the files here:

| File | What it is |
|---|---|
| `engine.js` | `LetterEngine`: letter stroke templates, guide-dot layout, tracing-coverage check, $P free-draw recognizer, final verdict (pass / almost / other / scribble / retry) |
| `arbiter.js` | `createTouchArbiter`: decides which touch may draw (one finger draws; resting hand doesn't block; two-finger, pinch, palm and edge-grip touches rejected; stylus wins) |
| `garden.js` | `GARDEN_ITEMS`: fruit & vegetables, about 4 per letter (104), hand-drawn inline SVG (generated by `garden_make.py` + `garden_more_*.py`; `garden_sheet.py` renders a contact sheet) |
| `sports.js` | `SPORTS_ITEMS`: sports things, 4 per letter (X 3), SVG (generated by `sports_make.py` + `sports_more_*.py`) |
| `house.js` | `HOUSE_ITEMS`: household things, 4 per letter (X 3), SVG (generated by `house_make.py` + `house_more_*.py`) |
| `countries.js` | `COUNTRY_ITEMS`: a flag on a pole, 2–4 per letter (90 flags, incl. W World, X treasure map, sailors' signal flags for O/X/Y/Z) plus `COUNTRY_HOME_SVG` for the home button (generated by `countries_make.py` + `countries_more_*.py`; flag helpers in `countries_kit.py`) |
| `dinos.js` | `DINO_ITEMS`: cartoon dinosaurs (incl. flying and swimming reptiles), 45 over 20 letters; F, J, W, X, Y, Z have none and are skipped in the Dinos world (generated by `dinos_make.py` from `dinos_more_*.py`; style helpers in `dinos_kit.py`) |
| `*_more_*.py` | Extra pictures for a pack. Each defines `add_more(K)`; the matching `*_make.py` picks up every `<pack>_more_*.py` file (sorted by name) via `svgkit.add_extensions`, so new pictures can be added without touching the make script |
| `more_sheet.py` | Safety checks + contact sheet for one extras file: `python tests/more_sheet.py house_more_nz sheet.png [tile] [LETTERS]` |
| `svgkit.py` | Drawing helpers shared by the pack scripts (outline, highlight, face, thick lines), `add_extensions`, and `Pack.write(..., allow_missing=True)` for packs that skip letters |
| `pack_sheet.py` | Contact sheet of any picture pack: `python tests/pack_sheet.py tests/sports.js sheet.png` |
| `voice.js` | `Voice` + `voiceId`: plays the recorded clip `voice/<id>.mp3` for a line (WebAudio, or an `<audio>` element on old browsers), chains two-part lines, preloads the current letter's clips, and calls back to the browser voice when any clip is missing or slow |
| `voice_lines.js` | Lists every line the game can say and writes `../tools/voice_script.tsv` (id, text, group) in upload order: prompts, then Zoo, Garden, Sports, House, Countries, Dinos. Run it after adding pictures |
| `k_browser_test.py` | Headless Chromium check that a small k is not passed after the stem and the arm (no win on the finger lift, "Almost" at the pause, win after the leg) |
| `voice_browser_test.py` | Headless Chromium check (Playwright) of clip playback, two-part lines, missing-clip fallback, no-WebAudio, sound off, service-worker caching and offline |
| `game.js` | Game controller: worlds (Zoo / Garden / Sports / House / Countries / Dinos; Zoo has 4 emoji animals per letter; a world may play only some letters via `letters`), random picture per letter (never the same twice in a row), ◀ / ▶ letter buttons, home screen and back button, picture fitted above the words (fitPicture), "Keep it upright" button, ABC ⇄ abc, school lines, canvas rendering, pointer wiring, guide dots, voice, celebration flow, saved progress |
| `build.py` | Rebuilds (engine, arbiter, voice, packs, game) the `<script>` block in `../index.html` from the files above and syntax-checks it |

## Workflow

```
# edit engine.js / arbiter.js / game.js (or a *_make.py, then run it), then:
python tests/build.py
cd tests
node test_arbiter.js     # 17 touch scenarios
node sim.js              # simulated preschool handwriting (env: N, W, H, LEN, SET=lower)
node smoke_dom.js        # headless walk-through of ../index.html: home, Zoo, idle auto-check, abc, i-dot, ◀/▶, random pictures, Garden, Sports, House, Countries, Dinos (skipped letters)
cd ..
python tests/voice_browser_test.py   # needs: pip install playwright; python -m playwright install chromium-headless-shell
python tests/k_browser_test.py       # small k must wait for the leg
```

## Recorded voice

Clips normally live in `voice/`. They can also sit in `<folder>/voice/` (the first upload put them in
`stage01/voice/` … `stage08/voice/`): `python tests/build.py` scans for them and writes the list into
`VOICE_FOLDERS`, so rebuild after moving or adding clips. A clip in the top-level `voice/` wins.

Clip name rule: lowercase the text, drop accents, turn every run of other characters into "-":
"Can you trace little A?" → `voice/can-you-trace-little-a.mp3`, "B is for Brachiosaurus" →
`voice/b-is-for-brachiosaurus.mp3`. `tools/voice_script.tsv` has the full list.

```
node tests/voice_lines.js                     # refresh tools/voice_script.tsv
pip install kokoro-onnx soundfile             # + ffmpeg on the PATH
python tools/record_kokoro.py --model-dir <folder with kokoro-v1.0.int8.onnx + voices-v1.0.bin>
python tools/record_kokoro.py --only b-is-for-bear   # re-record one clip
python tools/record_kokoro.py --show --only ...      # print the phonemes without recording
```

Only missing clips are recorded. Pronunciation fixes go in `SAY_AS` in `record_kokoro.py`
(IPA between slashes). A "?" after a letter that ends in an "ee" sound (B, C, D, E, G, P, T, V, Z)
is read as "!", because Kokoro otherwise glides it into "deer?" or "peer?".

`SET=lower node sim.js` runs the same simulation on the lowercase letters (on school lines).
`ENGINE=./orig_engine.js node sim.js` runs it against the original recognizer (baseline).
`LOWER_R`, `STRAY0`, `STRAY1`, `STRAY2` override the tuning constants for calibration runs only.
The same goes for the stroke-end rules: `ENDS_LIVE` (1.5), `ENDS_PAUSE` (2.0) and `ENDS_GATE` (2.5) are distances in R. `LIVE_OVERALL` (0.9) and `LIVE_STROKE` (0.8) set the coverage needed to finish on a finger lift.
The rows "finger lift, …" test the check at each finger lift (`final: false`). The rows "stopped at 80%" leave the last stroke unfinished.

Results at 640×520, 520 attempts per row (update 9, November 2026):

| Scenario | Original | Uppercase | Lowercase |
|---|---|---|---|
| Good trace → pass | 100% | 99.2% | 99.4% |
| Sloppy trace → pass | 100% | 97.1% | 96.3% |
| Missing stroke → not passed | 42% | 95.4% | 94.8% |
| Half traced → not passed | 0% | 99.8% | 96.7% |
| Stopped at 80% → not passed (pause check) | – | 70.6% | 57.9% |
| Good trace → finished on the finger lift | – | 84.8% | 90.2% |
| Stopped at 80% → no finish on the finger lift | – | 94.4% | 82.3% |
| Zig-zag scribble → not passed | 0% | 94.6% | 86.5%* |
| Loop scribble → not passed | 0% | 100% | 100% |
| Random scribble → not passed | 0% | 99.4% | 98.3% |
| Wrong letter on guide → not passed | 0% | 95.2% | 91.3% |
| Free-drawn target off guide → pass | 100% | 96.5% | 94.0% |
| Free-drawn other letter → recognised | – | 98.8% | 96.5% |

\* Most lowercase zig-zag "passes" are on i, l and j: a ±20 px zig-zag down a single straight
line is, in effect, a wobbly trace of that line. Without those three letters the figure is about 93%.

## Lowercase notes

- Lowercase templates sit on school lines: top line y=0, dashed midline y=45, baseline y=100,
  descender line y=132 (`RULE` in `engine.js`). All lowercase letters share one scale, so "o" is
  short, "h" is tall and "p" hangs below the baseline, as on paper.
- Finger tolerance is 10% of the top-line-to-baseline height (`LOWER_R`), the same for every
  lowercase letter.
- The free-draw recognizer only compares a letter with others of the same case.
- The dots on i and j are taps: a tap within reach of the dot counts as ink.
- `strayFrac` (share of ink far from the guide) stops a different letter that happens to cover a
  short guide from passing.
